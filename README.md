# Circuit

Interactive, module-based spreadsheet learning platform for secondary school classrooms. Part of the Edufied suite.

## Project info

Circuit delivers self-paced, module-based digital skills training built for the classroom. Students work through real software — teachers stay in control.

## Tech stack

- Vite
- TypeScript
- React 18
- shadcn/ui
- Tailwind CSS
- Supabase (Postgres + Auth + Edge Functions)
- FortuneSheet (embedded spreadsheet engine)

## Getting started

```sh
# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build
```

## Environment variables

Copy `.env.example` to `.env` and fill in your Supabase credentials.
